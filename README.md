# The Book Tell Tomorrow

**The Book Tell Tomorrow** is a story-based web project featuring a mysterious world, unique characters, and a visually immersive card-based layout.

## About the Project

This website presents the story and its main characters through a clean and creative interface. Each character is displayed in a dedicated card, while **The Keeper** is placed at the center to create a distinctive visual composition.

## Characters

- **Ayla**
- **Rayyan**
- **Zoya**
- **Adam**
- **The Keeper**

## Features

- Story-based interactive layout
- Character profile cards
- Unique 2×2 card arrangement
- Centered Keeper character section
- Responsive design
- Themed typography and colors
- Background imagery for an immersive storytelling experience

## Design

The website uses a warm, storybook-inspired visual style with:

- Cream and beige tones
- Gold borders
- Elegant typography
- Character-focused card design
- Atmospheric background imagery

## Technologies Used

- HTML5
- CSS3
